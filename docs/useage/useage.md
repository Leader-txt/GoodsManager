> 版本：v1.0 | 最后更新：2026-06-03

---

## 1. 系统简介

联想旗舰店商品管理系统是一套 B/S 架构的全栈商品管理平台，支持**线上自助购物**和**线下门店销售**双渠道业务。系统覆盖商品浏览、购物车、订单交易、库存管理、顾客管理、系统日志六大核心模块。

### 1.1 系统地址

| 服务 | 地址 |
|------|------|
| 前端页面 | `http://localhost:5173` |
| 后端 API | `http://localhost:3000` |
| 健康检查 | `http://localhost:3000/api/health` |

### 1.2 支持的商品类型

笔记本电脑、台式机、平板、智能手机、蓝牙耳机、摄像头、投影仪、电视、键盘、鼠标（共 10 种）。

## 2. 用户角色概览

系统共有四种用户角色，不同角色拥有不同的功能权限：

| 角色 | 职责概述 | 手册链接 |
|------|----------|----------|
| **普通顾客** | 浏览商品、注册登录、管理购物车、下单支付、查看订单 | [顾客使用说明](customer.md) |

## 3. 快速入门

### 3.1 系统启动

> 前置要求：Node.js ≥ 18、Docker & Docker Compose

```bash
# 第一步：启动 MySQL 数据库
cd database
docker-compose up -d

# 第二步：启动后端服务
cd backend
cp .env.example .env
npm install
npm run dev

# 第三步：启动前端服务
cd frontend
npm install
npm run dev
```

## 6. 通用操作说明

### 6.1 用户登录

1. 访问 `http://localhost:5173/login`
2. 输入用户名和密码
3. 点击"登录"按钮
4. 登录成功后，系统根据角色自动跳转到对应页面：
   - 顾客 → 首页
   - 销售人员 → 工作台
   - 仓库操作员 → 库存管理
   - 管理员 → 管理后台仪表盘

### 6.2 顾客注册

1. 访问 `http://localhost:5173/register`
2. 填写用户名（手机号）、密码、姓名、性别、身份证号
3. 点击"注册"按钮
4. 注册成功后跳转登录页

> **注意**：姓名、性别、身份证号注册后不可修改，请仔细核对。

### 6.3 导航栏说明

```
┌──────────────────────────────────────────────────────────────┐
│  🏠 Logo    [商品]  [我的订单]         [🛒 购物车(3)]  [👤 用户] │
└──────────────────────────────────────────────────────────────┘
```

- **商品**：浏览全部商品
- **我的订单**：查看订单列表（需登录）
- **购物车图标**：角标数字显示购物车中的商品种类数
- **用户菜单**：个人信息、退出登录

### 6.4 退出登录

点击导航栏右侧用户菜单 → 选择"退出登录"。

## 7. API 响应格式

所有后端接口统一返回以下 JSON 格式：

```json
{
  "code": 200,
  "message": "ok",
  "data": {}
}
```

| code | 含义 |
|:----:|------|
| 200 | 操作成功 |
| 400 | 请求参数错误 |
| 401 | 未登录或 Token 已过期 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 9. 常见问题

### Q: 忘记密码怎么办？

请联系管理员重置密码。管理员可在管理后台 → 销售人员管理中为销售人员重置密码。顾客密码暂不支持自助找回，请联系门店工作人员。

### Q: 订单多久不支付会自动取消？

选择"在线支付"的订单，若 24 小时内未完成支付，系统会自动取消并退回库存。

### Q: 为什么商品显示"暂时缺货"？

当商品库存为 0 时，系统会自动标记为缺货状态，此时无法加入购物车或购买。请联系门店咨询补货时间。

### Q: 购物车中的商品会一直保留吗？

已登录顾客的购物车数据存储在数据库中，不会因为关闭浏览器而丢失。但商品价格和库存状态会实时变化，结算时会再次校验。

### Q: 可以修改已提交的订单吗？

订单一旦提交不可修改。待支付状态的订单可以取消后重新下单。
