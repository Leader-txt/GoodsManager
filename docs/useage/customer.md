# 顾客使用说明

> 适用角色：普通顾客 (customer)
> 阅读本文前，建议先阅读 [总用户手册](useage.md) 了解系统基本概念。

---

## 1. 顾客功能概览

作为顾客，您可以在系统中完成以下操作：

| 功能模块 | 具体操作 |
|----------|----------|
| 账号管理 | 注册账号、登录系统、修改手机号、修改收货地址 |
| 商品浏览 | 浏览商品列表、按类型筛选、关键字搜索、查看商品详情和规格参数 |
| 购物车 | 加入购物车、修改数量、删除商品、选择结算 |
| 订单管理 | 提交订单、在线支付、查看订单列表/详情、取消订单、确认签收 |

---

## 2. 注册与登录

### 2.1 注册新账号

1. 在浏览器中访问系统地址，点击导航栏或页面上的"注册"按钮（或直接访问 `/register`）
2. 填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 用户名 | 11 位中国大陆手机号 | `13800138000` |
| 密码 | 6-20 位，必须包含字母和数字 | `abc123` |
| 确认密码 | 与密码一致 | `abc123` |
| 姓名 | 2-20 个中文字符 | `张三` |
| 性别 | 男 / 女 | `男` |
| 身份证号 | 18 位有效身份证号 | `310101199001011234` |

3. 点击"注册"按钮提交
4. 注册成功后，页面自动跳转到登录页

> ⚠️ **重要提示**：姓名、性别、身份证号注册后**不可修改**，请务必仔细核对后再提交。

### 2.2 登录系统

1. 访问登录页面 `/login`
2. 输入用户名和密码
3. 点击"登录"按钮
4. 登录成功后自动跳转到首页

> 登录状态保持 7 天，超期需重新登录。

### 2.3 修改个人信息

1. 登录后，点击导航栏右侧用户菜单 → "个人信息"（或访问 `/profile`）
2. 在个人信息页面：
   - **只读字段**（灰色）：姓名、性别、身份证号 —— 不可修改
   - **手机号**：输入新手机号，点击旁边的"保存"按钮
   - **收货地址**：输入新地址，点击旁边的"保存"按钮

## 3. 浏览商品

### 3.1 商品列表

访问首页 `/` 或商品列表页 `/products`，系统以卡片网格形式展示所有上架商品。

每个商品卡片显示：
- 商品图片
- 商品名称
- 商品类型标签
- 销售价格（¥）
- 当前库存数量
- 缺货商品显示半透明遮罩 + "暂时缺货"文字

### 3.2 搜索与筛选

在商品列表页顶部，您可以使用以下功能缩小查找范围：

| 功能 | 操作方式 | 说明 |
|------|----------|------|
| 关键字搜索 | 在搜索框输入商品名称 | 支持模糊搜索，输入后自动搜索（300ms 防抖） |
| 类型筛选 | 点击类型标签 | 如"笔记本电脑"、"平板"、"手机"等，单选 |
| 品牌筛选 | 选择品牌 | 根据当前类型动态加载可选品牌 |
| 排序 | 选择排序方式 | 默认（最新上架）、价格从低到高、价格从高到低 |
| 分页 | 点击页码或上一页/下一页 | 每页显示 12 个商品 |

### 3.3 商品详情

点击商品卡片上的"详情"按钮或商品图片，进入商品详情页 `/products/:id`。

详情页展示内容：
- **左侧**：商品大图
- **右侧**：商品名称、品牌、价格、库存状态
- **操作按钮**："加入购物车"（缺货时按钮禁用）
- **下方**：规格参数表格，按分组展示（如基本信息、核心配置、屏幕、物理特性等）

## 4. 购物车

> 购物车功能需要登录后才能使用。未登录点击"加入购物车"会弹出登录提示。

### 4.1 加入购物车

**方式一：从商品详情页加入**

1. 在商品详情页点击"加入购物车"按钮
2. 在弹出的数量选择框中，使用 `+`/`-` 按钮调整数量（默认为 1，上限为当前库存数）
3. 点击确认，页面右上角弹出"已加入购物车"提示

**方式二：从商品列表页快速加入**

1. 在商品列表页，将鼠标悬停在商品卡片上
2. 点击出现的"加入购物车"按钮

> 如果购物车中已有该商品，再次加入时会**合并数量**（新数量 = 已有数量 + 本次添加数量），不会创建重复条目。

### 4.2 管理购物车

点击导航栏右侧的购物车图标 🛒，进入购物车页面 `/cart`。

```

│  ├────┼─────────────────┼────────┼────────┼──────────┤  │
```

购物车操作说明：

| 操作 | 如何操作 | 说明 |
|------|----------|------|
| 修改数量 | 点击 `+`/`-` 按钮 | 最少为 1，修改后自动保存 |
| 删除商品 | 点击"删除"按钮 | 弹出确认提示，防止误删 |
| 选中/取消 | 勾选复选框 | 可全选/取消全选；仅选中的商品参与结算 |
| 查看库存状态 | 查看库存标签 | 库存不足时行内标红提示，不可选中 |

### 4.3 导航栏角标

导航栏购物车图标右上角的数字表示购物车中的**商品种类数**（不是总件数）。

## 5. 下单与支付

### 5.1 提交订单

1. 在购物车页面，勾选要购买的商品
2. 点击"去结算"按钮，进入结算页 `/checkout`

结算页包含以下内容：

**（1）收货地址**

- 默认加载您最近使用的收货地址
- 也可选择"使用新地址"，输入新地址后确认
- 如果尚未设置地址，请先在个人信息页添加

**（2）商品清单**

- 展示从购物车带入的商品名称、单价、数量、小计
- 底部显示合计金额

**（3）支付方式（二选一）**

| 支付方式 | 说明 |
|----------|------|
| 在线支付 | 订单创建后需在 24 小时内完成支付，超时自动取消 |
| 货到付款 | 订单创建后直接生效，无需等待支付 |

**（4）提货方式（二选一）**

| 提货方式 | 说明 |
|----------|------|
| 送货上门 | 需填写收货地址，后续会有快递配送 |
| 自行提货 | 无需地址，到店自取 |

3. 确认所有信息后，点击"提交订单"
4. 系统进行最终库存校验：
   - 库存充足 → 订单创建成功，跳转订单详情页
   - 库存不足 → 提示错误，阻止提交

### 5.2 支付订单

- **在线支付订单**：在订单详情页或订单列表页，点击"去支付"按钮，系统模拟支付流程，确认后订单状态变为"已支付"
- **货到付款订单**：提交订单后自动变为"已支付"状态，无需额外操作

> 本系统当前使用**模拟支付**，点击支付后直接确认完成。

### 5.3 查看订单

点击导航栏"我的订单"，进入订单列表页 `/orders`。

操作说明：

| 按钮 | 出现条件 | 功能 |
|------|----------|------|
| 查看详情 | 全部订单 | 查看订单完整信息、状态时间线、物流信息 |
| 去支付 | 待支付 + 在线支付 | 前往支付页面完成支付 |
| 取消订单 | 待支付 | 取消该订单，库存自动退回 |
| 确认收货 | 配送中 | 确认收到商品，订单变为"已签收" |

### 5.4 订单详情

点击"查看详情"进入订单详情页 `/orders/:id`：

- **状态时间线**：可视化展示订单从创建到完成的完整流转过程
- **订单信息**：订单编号、创建时间、支付方式、提货方式、收货地址
- **商品明细**：商品名称、图片、单价、数量、小计
- **物流信息**：送货上门订单显示快递公司和快递单号

### 5.5 取消订单

1. 在订单列表页，找到待支付的订单
2. 点击"取消订单"
3. 在确认弹窗中点击"确认"
4. 订单状态变为"已取消"，库存自动退回

> 📌 仅**待支付**状态的订单可以取消。已支付及之后的订单不可取消。

### 5.6 确认签收

1. 在订单列表页，找到配送中的订单
2. 点击"确认收货"
3. 在确认弹窗中点击"确认"
4. 订单状态变为"已签收"

---

## 6. 订单状态说明

| 状态 | 含义 | 您的操作 |
|------|------|----------|
| 待支付 | 订单已创建，等待支付 | 去支付 或 取消订单 |
| 已支付 | 支付已完成，等待仓库出货 | 等待 |
| 已出库 | 商品已从仓库发出 | 等待物流 |
| 配送中 | 快递正在配送 | 确认收货 |
| 已签收 | 已确认收货，交易完成 | 无 |
| 已取消 | 订单已取消 | 无 |

---

## 7. 操作流程速查

### 线上购买完整流程

```
注册/登录 → 浏览商品 → 加入购物车 → 进入购物车 →
勾选商品 → 去结算 → 确认地址 → 选择支付方式 →
选择提货方式 → 提交订单 →
  ├── 在线支付：去支付 → 等待发货 → 确认收货
  └── 货到付款：等待发货 → 确认收货
```

---

## 8. 注意事项

1. **实名信息不可改**：姓名、性别、身份证号注册后锁定，请仔细核对
2. **超时自动取消**：在线支付订单 24 小时内未支付将被系统自动取消
3. **库存实时变化**：加入购物车时库存充足不代表结算时仍有库存，系统会在结算时再次校验
4. **价格快照**：订单中的商品价格以下单时为准，后续商品调价不影响已有订单
5. **购物车持久化**：登录状态下的购物车数据保存在服务器，不会因关闭浏览器而丢失
