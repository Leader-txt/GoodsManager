# 仓库操作员使用说明

> 适用角色：仓库操作员 (warehouse)
> 阅读本文前，建议先阅读 [总用户手册](useage.md) 了解系统基本概念。

---

## 1. 仓库操作员功能概览

作为仓库操作员，您负责管理仓库的货架和商品库存：

| 功能模块 | 具体操作 |
|----------|----------|
| 货架管理 | 添加货架、编辑货架、删除货架 |
| 库存管理 | 查看库存总览、搜索商品库存、库存预警、单个商品出入库历史 |
| 入库操作 | 总部供货入库、退货入库、盘点调整入库 |
| 出库操作 | 销售出库（关联订单）、批量出库、其他出库（报损/退货） |
| 仓库订单 | 查看待出库订单、一键发货 |

---

## 2. 登录系统

1. 访问 `http://localhost:5173/login`
2. 输入您的用户名和密码
3. 登录成功后进入库存管理页面

> 预置测试账号：`warehouse01` / `abc123`

## 3. 货架管理

仓库中的商品按货架存放，货架编号采用 `A-B-C` 三层编码体系。

### 3.1 货架编号规则

```
格式：A-B-C

A — 货架编号（数字，如 1, 2, 3...）
B — 层数（数字，从 1 开始）
C — 该层上的具体位置（数字，从 1 开始）

示例：
  3-2-5 → 3号货架 第2层 第5号位
  1-1-1 → 1号货架 第1层 第1号位
```

### 3.2 查看货架列表

进入货架管理页面，以表格形式展示所有货架：

```
┌──────┬──────────┬──────────┬──────────┬────────┐
│ ID   │ 货架编号  │ 描述      │ 存放商品  │ 操作    │
├──────┼──────────┼──────────┼──────────┼────────┤
│  1   │ 1-1-1    │ 笔记本区   │ 拯救者R9000P│ [编辑]  │
│  2   │ 1-1-2    │ 笔记本区   │ ThinkPad X1│ [编辑]  │
│  3   │ 2-3-5    │ 配件区    │ 联想鼠标    │ [编辑]  │
└──────┴──────────┴──────────┴──────────┴────────┘
```

### 3.3 添加货架

1. 在货架管理页面，点击"添加货架"按钮
2. 在弹窗中填写：

| 字段 | 说明 | 示例 |
|------|------|------|
| 货架编号 | 格式 `数字-数字-数字`，每段 1-99，全局唯一 | `4-1-1` |
| 描述 | 货架用途说明 | `台式机区` |

3. 点击"确认添加"

### 3.4 编辑货架

1. 在货架列表中找到目标货架
2. 点击"编辑"按钮
3. 修改货架编号或描述
4. 点击"确认修改"

### 3.5 删除货架

1. 在货架列表中找到目标货架
2. 点击"删除"按钮
3. 系统会自动校验：

   - ✅ 货架上无库存 → 删除成功
   - ❌ 货架上尚有商品 → 提示"该货架尚有商品，请先转移库存"

> ⚠️ 只有空货架才能删除。如需删除非空货架，请先将该货架上的商品出库或转移到其他货架。

## 4. 库存管理

### 4.1 库存总览

进入库存管理页面，查看所有商品的库存状况：

```
┌────┬────────────┬──────────┬──────┬────────┬────────┐

├────┼────────────┼──────────┼──────┼────────┼────────┤
│  1 │ 拯救者R9000P│ R9000P    │ 1-1-1│  10    │ [详情]  │
│  2 │ ThinkPad X1│ X1 Carbon │ 1-1-2│   0 🔴 │ [详情]  │
│  3 │ 联想鼠标    │ 无线蓝牙  │ 2-3-5│   2 🟡 │ [详情]  │
└────┴────────────┴──────────┴──────┴────────┴────────┘
```

### 4.2 库存搜索与筛选

| 功能 | 操作方式 | 说明 |
|------|----------|------|
| 关键字搜索 | 搜索框输入商品名称/编号 | 模糊搜索 |
| 类型筛选 | 下拉选择商品类型 | 如"笔记本电脑"、"鼠标"等 |
| 库存状态 | 选择状态标签 | 全部 / 有货(>0) / 缺货(=0) / 低库存(<5) |

### 4.3 库存预警

系统通过**颜色标识**提示库存状态：

| 颜色 | 含义 | 库存范围 |
|:----:|------|:--------:|
| 🟡 黄色 | 低库存预警 | 1-4 件 |
| 🔴 红色 | 缺货 | 0 件 |

> 看到黄色预警时，请及时关注；红色缺货时请尽快安排入库。

## 5. 入库操作

### 5.1 入库触发场景

| 场景 | 说明 |
|------|------|
| 总部供货 | 每周联想总部定期供货，批量入库 |
| 退货入库 | 顾客退货验收后重新入库 |
| 盘点调整 | 盘点发现盈余，修正库存 |

### 5.2 入库操作步骤

1. 在库存管理页面，点击"入库"按钮
2. 在入库弹窗中填写：

```
┌──────────────────────────────────────┐
│  商品入库                             │
├──────────────────────────────────────┤
│  商品：  [搜索选择商品...        ▼]   │
│  型号：  [自动带出]                   │
│  入库数量：[          ]              │
│  目标货架：[选择货架...         ▼]   │
│  备注：  [                ]  (选填)  │
│                                      │
│         [确认入库]   [取消]           │
└──────────────────────────────────────┘
```

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 商品 | ✅ | 搜索下拉选择要入库的商品 |
| 入库数量 | ✅ | 必须大于 0 |
| 目标货架 | ✅ | 选择商品存放的货架 |
| 备注 | | 如"总部供货"、"退货入库"等 |

3. 点击"确认入库"
4. 系统自动更新库存数量（如该货架上已有此商品则累加数量，否则新增一条记录）
5. 系统自动记录入库日志

## 6. 出库操作

### 6.1 出库触发场景

| 场景 | 说明 |
|------|------|
| 销售出库 | 订单支付后，按订单出货 |
| 其他出库 | 退货给供应商、商品报损等 |

### 6.2 出库操作步骤（关联订单）

1. 在库存管理页面，点击"出库"按钮
2. 在出库弹窗中：

```
┌──────────────────────────────────────┐
│  商品出库                             │
├──────────────────────────────────────┤
│  关联订单：[搜索/输入订单号...  ▼]    │
│  商品：  [自动带出订单中的商品]        │
│  出库数量：[自动带出，可调整]          │
│  所在货架：[自动带出当前存放货架]      │
│  备注：  [                ]  (选填)  │
│                                      │
│         [确认出库]   [取消]           │
└──────────────────────────────────────┘
```

3. **关联订单出库**：
   - 选择已支付的订单，系统自动带出商品和数量
   - 确认出库后，订单状态自动更新为"已出库"

4. **无关联订单出库**（报损/退货给供应商）：
   - 不选择关联订单
   - 手动选择商品、输入出库数量
   - 在备注中说明出库原因

### 6.3 出库校验

系统在出库时自动进行以下校验：

| 校验项 | 说明 |
|--------|------|
| 库存充足 | 出库数量不得大于当前库存，否则操作失败 |
| 数量有效 | 出库数量必须大于 0 |

## 7. 仓库订单管理

进入"待出库订单"页面（导航栏 → 待出库订单），查看所有已支付待出库的订单：

```
┌──────────┬────────┬──────────┬──────┬────────┬──────────┐
│ 订单号    │ 顾客    │ 金额      │ 状态  │ 提货方式 │ 操作      │
├──────────┼────────┼──────────┼──────┼────────┼──────────┤
│2024060101│ 张三   │¥8,999    │已支付│ 送货上门 │[一键发货] │
│2024052803│ 李四   │¥6,697    │已支付│ 自提     │[一键发货] │
└──────────┴────────┴──────────┴──────┴────────┴──────────┘
```

### 操作说明

- 点击订单行可展开查看订单详细信息（顾客信息、商品明细、物流信息）
- 点击"一键发货"按钮：
  - **送货上门订单**：需填写快递公司和快递单号，点击确认后订单状态变为"已出库"
  - **自提订单**：点击确认后订单状态直接变为"已签收"
- 支持按订单状态筛选（默认显示"已支付"状态）

## 8. 库存自动扣减说明

> 本系统采用**支付成功自动扣减库存**的策略。

| 事件 | 库存变化 | 说明 |
|------|:--------:|------|
| 顾客支付成功 | 自动扣减 | 系统自动扣减对应商品库存 |
| 订单超时取消 | 自动回退 | 系统自动将被取消订单的库存退回 |
| 仓库操作员出库 | 确认动作 | 更新订单状态为"已出库"，写出入库日志 |

这意味着：
- 顾客支付成功后，库存已自动扣减
- 您的出库操作主要是**确认发货**（更新订单状态），而非再次扣减库存
- 您仍可手动出库（如报损），但销售出库建议关联订单操作

## 9. 操作流程速查

### 总部供货入库流程

```
收到货物 → 核对清单 → 打开入库页面 →
选择商品 → 输入入库数量 → 选择货架 →
备注"总部供货" → 确认入库 → 完成
```

### 订单出库流程

```
收到出库通知 → 打开出库页面 →
选择关联订单 → 确认商品和数量 →
确认出库 → 订单状态自动更新 → 交付物流
```

---

## 10. 注意事项

1. **货架编号规范**：严格按照 `A-B-C` 格式创建货架编号，确保全局唯一
2. **先转移再删除**：删除货架前，确保货架上无库存。如有库存，先出库转移
3. **出库数量限制**：出库数量不能超过当前库存，操作前请确认库存充足
4. **备注清晰**：出入库时请填写清晰的备注，方便后续追溯。关联订单出库时备注会自动生成
5. **日志不可删改**：出入库日志一旦生成不可修改或删除，请仔细核对后再确认操作
6. **库存预警响应**：关注黄色和红色库存预警，及时安排补货入库
