# 销售人员使用说明

> 适用角色：销售人员 (sales)
> 阅读本文前，建议先阅读 [总用户手册](useage.md) 了解系统基本概念。

---

## 1. 销售人员功能概览

作为销售人员，您在门店现场为顾客提供面对面的销售服务：

| 功能模块 | 具体操作 |
|----------|----------|
| 工作台 | 销售工作台首页，功能入口导航 |
| 顾客管理 | 为线下顾客注册账号 |
| 订单管理 | 创建线下订单、确认现场结付、录入物流信息、查看历史订单 |
| 商品浏览 | 查看商品列表和详情（帮助顾客选购） |

---

## 2. 登录系统

使用管理员分配的账号登录系统：

1. 访问 `http://localhost:5173/login`
2. 输入您的用户名和密码
3. 登录成功后进入工作台

> 预置测试账号：`sales01` / `abc123`

---

## 3. 为线下顾客注册

线下到店的新顾客，由您协助完成系统注册。

### 3.1 操作步骤

1. 登录后，在工作台找到"线下注册顾客"功能入口
2. 填写顾客信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 姓名 | 2-20 个中文字符，注册后不可修改 | `李四` |
| 性别 | 男 / 女，注册后不可修改 | `女` |
| 身份证号 | 18 位有效身份证号，注册后不可修改 | `110101199502022345` |
| 手机号 | 11 位手机号（可选） | `13900139000` |

3. 点击"确认注册"
4. 系统自动生成：
   - **用户名**：手机号（如有）或身份证号后 8 位 + 随机 2 位字符
   - **初始密码**：身份证号后 6 位

5. 注册成功后，页面会显示生成的用户名和初始密码：

```
┌──────────────────────────────────────┐
│  注册成功                             │
├──────────────────────────────────────┤
│  用户名：950202345ab                  │
│  初始密码：022345                     │
│                                      │
│  请将以上信息告知顾客                   │
│  建议顾客首次登录后修改密码             │
│                                      │
│              [确定]                   │
└──────────────────────────────────────┘
```

6. **口头告知顾客**用户名和初始密码，并提醒顾客首次登录后修改密码

> ⚠️ 姓名、性别、身份证号注册后**不可修改**，请务必与顾客核对无误后再提交！

---

## 4. 创建线下订单

顾客在门店选中商品后，由您在系统中创建线下订单。

### 4.1 操作步骤

1. 登录后，进入"创建线下订单"功能页面
2. **第一步：选择顾客**
   - 在搜索框中输入顾客的姓名、手机号或身份证号进行搜索
   - 从搜索结果中选择目标顾客
   - 如果是新顾客，先完成线下注册（参考第 3 节）

3. **第二步：添加商品**
   - 搜索并选择顾客要购买的商品
   - 输入购买数量
   - 可添加多种商品
   - 系统会自动校验库存，库存不足时提示

4. **第三步：确认订单**
   - 线下订单支付方式固定为"现场结付"
   - 选择提货方式（自行提货 / 送货上门）
   - 送货上门需填写收货地址、快递公司、快递单号
   - 确认顾客已完成付款（现金/刷卡/扫码）
   - 点击"确认创建订单"

| 提货方式 | 后续操作 | 订单最终状态 |
|----------|----------|:----------:|
| **自行提货** | 顾客直接带走商品，订单完成 | 已签收 |
| **送货上门** | 需录入收货地址和快递信息 | 已支付（待发货） |

### 4.2 送货上门 — 录入物流信息

如果顾客选择送货上门，需要录入以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 收货地址 | 顾客提供的详细收货地址 | `上海市浦东新区XXX路XXX号` |
| 快递公司 | 发货快递公司名称 | `顺丰速运` |
| 快递单号 | 快递单号 | `SF1234567890` |

这些信息将显示在顾客的订单详情页中，顾客可据此跟踪物流。

---

## 5. 查看订单记录

进入"线下订单记录"页面（导航栏 → 销售工作台），可查看您创建的所有线下订单：

- 支持按订单状态筛选（待支付/已支付/已出库/配送中/已签收/已取消）
- 点击订单可查看完整详情（商品明细、物流信息等）
- 送货上门的订单可在此录入或修改快递信息

---

## 6. 线下订单与线上订单的区别

| 对比维度 | 线上订单 | 线下订单 |
|----------|----------|----------|
| 创建人 | 顾客自己 | 销售人员 |
| 支付方式 | 在线支付 / 货到付款 | 现场结付 |
| 支付时效 | 在线支付 24h 内完成 | 当场结付 |
| 超时取消 | 适用（在线支付） | 不适用 |
| 自提流程 | 待支付 → 已支付 → 已签收 | 待支付 → 已签收（一次性完成） |

---

## 7. 商品浏览

销售人员也可以浏览商品列表和详情，帮助顾客了解商品信息：

- **商品列表**：支持按类型筛选、关键字搜索、排序
- **商品详情**：查看完整规格参数、库存状态

> 销售人员账号**不能**使用购物车功能和在线下单功能。

---

## 8. 操作流程速查

### 线下购买完整流程（销售人员视角）

```
顾客到店 → 搜索/注册顾客 → 添加商品到订单 →
确认订单（选择提货方式 + 录入物流信息）→ 确认现场结付 →
  ├── 自提：顾客带走商品 → 订单完成
  └── 送货上门：录入地址 + 快递信息 → 订单待发货
```

---

## 9. 常见场景处理

### 场景一：老顾客到店购买

1. 搜索顾客（姓名/手机号/身份证号）
2. 创建线下订单 → 添加商品
3. 确认结付 → 选择提货方式
4. 完成

### 场景二：新顾客到店购买

1. 先进行线下注册顾客
2. 告知顾客用户名和初始密码
3. 创建线下订单 → 添加商品
4. 确认结付 → 选择提货方式
5. 完成

### 场景三：顾客购买大件商品（台式机、电视等）

1. 正常创建线下订单
2. 提货方式选择"送货上门"
3. 仔细录入收货地址和快递信息
4. 告知顾客可通过网站查看物流信息

---

## 10. 注意事项

1. **顾客信息准确性**：注册时务必核对顾客的姓名、性别、身份证号，这些信息注册后不可修改
2. **密码安全**：告知顾客初始密码后，务必建议其首次登录后修改密码
3. **库存校验**：添加商品时系统会校验库存，库存不足无法添加。如遇缺货，请告知顾客预计补货时间
4. **现场结付确认**：请确保顾客已完成实际付款后，再在系统中确认结付
5. **物流信息**：送货上门的快递公司和单号请准确录入，顾客将以此跟踪物流
