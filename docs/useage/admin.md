# 管理员使用说明

> 适用角色：管理员 (admin)
> 阅读本文前，建议先阅读 [总用户手册](useage.md) 了解系统基本概念。

---

## 1. 管理员功能概览

作为系统管理员，您拥有最高权限，负责系统的全局管理和监控：

| 功能模块 | 具体操作 |
|----------|----------|
| 仪表盘 | 查看今日订单、待处理、缺货、销售等关键指标 |
| 销售人员管理 | 添加/删除销售人员账号、重置密码 |
| 商品管理 | 添加/编辑/删除商品、上架/下架、维护规格参数 |
| 订单查看 | 查看系统中所有订单（含线上和线下） |
| 出入库日志 | 查看所有出入库操作记录 |
| 系统日志 | 查看完整操作日志，支持多维度筛选 |

---

## 2. 登录系统

1. 访问 `http://localhost:5173/login`
2. 输入管理员账号和密码
3. 登录成功后自动跳转到管理后台仪表盘

> 预置管理员账号：`admin` / `admin123`
> ⚠️ 首次登录后建议修改密码。

---

## 3. 管理后台导航

登录后，导航栏出现"管理后台"入口，管理后台包含以下页面：

| 页面 | 路径 | 功能 |
|------|------|------|
| 仪表盘 | `/admin/dashboard` | 全局数据概览 |
| 销售人员管理 | `/admin/sales` | 销售人员账号维护 |
| 商品管理 | `/admin/products` | 商品增删改、上下架 |
| 全部订单 | `/admin/orders` | 所有订单查看 |
| 出入库日志 | `/admin/inventory-log` | 出入库记录查看 |
| 系统日志 | `/admin/system-log` | 完整操作日志 |

## 5. 销售人员管理

### 5.1 查看销售人员列表

进入 `/admin/sales` 页面，表格展示所有销售人员：

```
┌────┬──────────┬──────────┬────────────────┬────────────┐
│ ID │ 用户名    │ 姓名      │ 创建时间        │ 操作        │
├────┼──────────┼──────────┼────────────────┼────────────┤
│ 10 │ sales01  │ 王销售    │ 2024-05-01 9:00│ [删除]      │
│ 11 │ sales02  │ 赵销售    │ 2024-05-15 14:30│ [删除]     │
└────┴──────────┴──────────┴────────────────┴────────────┘
```

### 5.2 添加销售人员

1. 在销售人员管理页面，点击"添加销售人员"按钮
2. 在弹窗中填写：

| 字段 | 说明 | 示例 |
|------|------|------|
| 用户名 | 4-20 位字母数字，全局唯一 | `sales03` |
| 密码 | 6-20 位 | `abc123` |
| 姓名 | 2-20 个中文字符 | `钱销售` |

3. 点击"确认添加"

### 5.3 删除销售人员

1. 在销售人员列表中找到目标销售
2. 点击"删除"按钮
3. 系统自动校验：

   - ✅ 无未完成订单 → 删除成功
   - ❌ 该销售有未完成订单 → 提示"该销售人员尚有未完成订单，请先处理"

### 5.4 重置销售人员密码

1. 在销售人员列表中找到目标销售
2. 点击"重置密码"
3. 系统生成 8 位随机新密码
4. 弹窗中显示新密码：

```
┌──────────────────────────────────────┐
│  密码重置成功                          │
├──────────────────────────────────────┤
│  销售人员：sales01                     │
│  新密码：aB3xK7mP                      │
│                                      │
│  请妥善告知该销售人员新密码              │
│  此密码仅显示一次，请立即记录            │
│                                      │
│              [确定]                   │
└──────────────────────────────────────┘
```

> ⚠️ 新密码仅在本次弹窗中显示一次，请立即记录并告知销售人员。

## 6. 商品管理

进入 `/admin/products` 页面，以表格形式管理所有商品。

### 6.1 商品列表（管理视图）

表格展示所有商品（含下架商品），每行包含操作按钮。

### 6.2 添加商品

1. 点击"添加商品"按钮
2. 填写商品基本信息：

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 商品名称 | ✅ | 如"联想拯救者 R9000P" |
| 商品类型 | ✅ | 下拉选择：笔记本电脑/台式机/平板... |
| 品牌 | ✅ | 如"联想" |
| 价格 | ✅ | 保留两位小数，如 `8999.00` |
| 商品图片 | | 上传商品主图 |

3. 填写规格参数（动态表单）：

```
┌──────────┬──────────────┬──────────┬──────┐
│ 分组      │ 参数名        │ 参数值    │ 操作  │
├──────────┼──────────────┼──────────┼──────┤
│ 基本信息  │ 品牌          │ 联想     │ [删除] │
│ 核心配置  │ 处理器        │ AMD R7   │ [删除] │
│ 核心配置  │ 内存          │ 16GB     │ [删除] │
└──────────┴──────────────┴──────────┴──────┘
[+ 添加一行参数]
```

- **分组**：参数所属分类，如"基本信息"、"核心配置"、"屏幕"等
- **参数名**：如"处理器"、"内存"、"屏幕尺寸"
- **参数值**：如"AMD R7"、"16GB"、"16.0英寸"

> 点击"添加一行参数"增加规格行；点击"删除"移除某行。

4. 点击"确认添加"

### 6.3 编辑商品

1. 在商品列表中找到目标商品
2. 点击"编辑"按钮
3. 修改商品基本信息或规格参数
4. 点击"确认修改"

> 编辑商品不会影响已有订单的价格（订单中存储的是下单时的价格快照）。

### 6.4 上架 / 下架

1. 在商品列表中找到目标商品
2. 点击"上架"或"下架"切换按钮
3. 状态立即生效：
   - **上架 (on)**：商品在前台展示，可被搜索和购买
   - **下架 (off)**：商品在前台隐藏，不可被顾客看到

### 6.5 删除商品

1. 在商品列表中找到目标商品
2. 点击"删除"按钮
3. 系统自动校验：

   - ✅ 无未完成订单关联 → 删除成功
   - ❌ 有未完成订单包含该商品 → 提示"该商品有关联的未完成订单，无法删除"

## 7. 全局订单查看

进入 `/admin/orders` 页面，查看系统中所有订单。

### 7.1 订单列表

```
┌──────────┬────────┬──────────┬──────┬────────┬──────────┐
│ 订单号    │ 顾客    │ 金额      │ 状态  │ 渠道   │ 操作      │
├──────────┼────────┼──────────┼──────┼────────┼──────────┤
│2024060101│ 张三   │¥8,999    │待支付│ 线上   │[查看详情] │
│2024052803│ 李四   │¥6,697    │配送中│ 线下   │[查看详情] │
└──────────┴────────┴──────────┴──────┴────────┴──────────┘
```

### 7.2 搜索与筛选

| 筛选条件 | 说明 |
|----------|------|
| 订单号 | 输入完整或部分订单号搜索 |
| 顾客姓名 | 模糊搜索顾客姓名 |
| 状态 | 下拉选择：全部/待支付/已支付/已出库/配送中/已签收/已取消 |
| 时间范围 | 选择起始日期和截止日期 |
| 渠道 | 查看"线上"或"线下"来源的订单 |

### 7.3 查看订单详情

点击"查看详情"可查看与顾客端相同的完整订单信息，包括状态时间线、商品明细、物流信息等。

> 📌 管理员**只能查看**订单，**不可修改**订单状态。状态变更由业务流程自动驱动。

## 10. 操作流程速查

### 添加新商品上架流程

```
进入商品管理 → 添加商品 → 填写基本信息 →
添加规格参数 → 保存 → 商品自动上架 →
顾客即可在前台看到
```

### 添加新销售人员流程

```
进入销售人员管理 → 添加销售人员 →
填写用户名、密码、姓名 → 保存 →
告知销售人员账号信息
```

### 处理缺货预警流程

```
查看仪表盘 → 发现缺货商品数 > 0 →
进入商品管理确认缺货商品 →
通知采购/总部补货
```

## 11. 注意事项

1. **管理员账号安全**：管理员拥有最高权限，请妥善保管账号密码，首次登录后建议修改密码
2. **不可修改订单状态**：管理员只能查看订单，不能手动修改订单状态。状态变更由业务流程（支付、出库、签收、取消）自动驱动
3. **删除前校验**：删除销售人员或商品时，系统会自动校验关联的未完成订单，有未完成订单则禁止删除
4. **密码仅显示一次**：重置销售人员密码后，新密码仅在弹窗中显示一次，请立即记录
5. **日志不可删改**：系统日志一旦写入不可修改或删除，确保审计追溯的完整性
6. **商品下架 ≠ 删除**：临时不希望商品展示，使用"下架"功能；确定不再销售时再"删除"
7. **规格参数维护**：不同商品类型可以有不同的规格参数，添加和编辑时请按分组整理
