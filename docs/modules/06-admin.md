# 模块六：管理后台

---

## 1. 模块概述

管理后台是**管理员**专属功能模块，提供销售人员管理、全局订单查看和出入库日志查看功能。管理后台的设计原则是"管理而非运营"——商品管理归属商品模块（见 [01-product.md](01-product.md)），出入库操作归属库存模块（见 [05-inventory.md](05-inventory.md)），本模块聚焦于人员管理和全局数据查看。

### 1.1 涉及角色

| 角色 | 可用功能 |
|------|----------|
| 管理员 | 全部管理后台功能 |
| 其他角色 | 不可访问（路由守卫拦截） |

### 1.2 涉及数据表

| 表名 | 说明 |
|------|------|
| `user` | 用户表（销售人员名单） |
| `order` | 订单表（全局查看） |
| `inventory_log` | 出入库日志表 |
| `system_log` | 系统日志表 |

### 1.3 后台入口

```
管理员登录后 → 导航栏出现"管理后台"入口 → 跳转 /admin/dashboard
```

## 6. 后端 API 设计

> 所有接口均需 JWT + admin 角色。

### 6.1 仪表盘

#### GET `/api/admin/dashboard` — 仪表盘数据

```json
{
  "code": 200,
  "data": {
    "todayOrders": 15,
    "pendingOrders": 3,
    "outOfStock": 5,
    "salesCount": 8,
    "recentOrders": [ /* 最近5条订单 */ ],
    "recentLogs": [ /* 最近5条出入库日志 */ ]
  }
}
```

---

### 6.2 销售人员管理

#### GET `/api/admin/sales` — 销售人员列表

分页查询 `user` 表中 `role = 'sales'` 的记录。不返回密码字段。

#### POST `/api/admin/sales` — 添加销售人员

```json
{
  "username": "sales03",
  "password": "abc123",
  "realName": "钱销售"
}
```

**处理逻辑：**

1. 校验用户名唯一
2. bcrypt 加密密码
3. INSERT `user`（role = 'sales'）
4. 返回新建销售人员信息（不含密码）

#### DELETE `/api/admin/sales/:id` — 删除销售人员

**前置校验：**

```sql
SELECT COUNT(*) FROM `order`
WHERE sales_id = :id AND status NOT IN ('signed', 'cancelled')
```

若 > 0，返回 400 "该销售人员尚有未完成订单，请先处理"。

#### POST `/api/admin/sales/:id/reset-password` — 重置密码

生成 8 位随机密码，bcrypt 加密后更新 `user.password`。返回新密码（仅在本次响应中返回，之后不可查询）。

---

### 6.3 全局订单查看

#### GET `/api/admin/orders` — 全部订单

参数同顾客订单列表，但查询范围为全部顾客。响应中增加 `salesName` 字段标识线下订单的销售人员。

---

### 6.4 出入库日志查看

#### GET `/api/admin/inventory-logs` — 出入库日志

参数见 [05-inventory.md](05-inventory.md#54-管理员接口) 5.4 节。

## 7. 业务规则

| 编号 | 规则 |
|:----:|------|
| BR-A01 | 管理员账号通过数据库初始化脚本创建（不提供注册入口），至少预置一个 admin 账号 |
| BR-A02 | 删除销售人员前校验其关联的未完成订单 |
| BR-A03 | 管理员可查看全局数据但不可修改订单状态（状态由业务流程驱动） |
| BR-A04 | 销售人员密码重置后，新密码仅在响应中返回一次，前端需弹窗醒目展示 |
| BR-A05 | 管理后台所有页面必须通过 JWT + admin 角色校验 |
| BR-A06 | 仪表盘统计数据为实时查询（非缓存），保证数据准确性 |

## 8. 数据库初始化 — 管理员预置

```sql
-- init.sql 中预置管理员账号
INSERT INTO `user` (username, password, role) VALUES
('admin', '$2b$10$...', 'admin');  -- 密码: admin123 (bcrypt加密后)
```

> 初始管理员账号：`admin` / `admin123`，首次登录后建议修改。

---

## 9. 数据库操作摘要

| 操作 | SQL 类型 | 说明 |
|------|:--------:|------|
| 仪表盘统计 | SELECT × 4 | 各统计项独立查询 |
| 销售人员列表 | SELECT | user WHERE role='sales' |
| 添加销售 | INSERT | user 表 |
| 删除销售 | DELETE | 校验通过后删除 user 记录 |
| 重置密码 | UPDATE | user.password |
| 全部订单 | SELECT + JOIN | order JOIN customer JOIN user |
| 出入库日志 | SELECT + JOIN | inventory_log JOIN user JOIN product |
