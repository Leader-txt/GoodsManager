# 模块二：用户认证与个人信息

---

## 1. 模块概述

用户认证模块负责**顾客注册、用户登录、个人信息管理**三大功能。系统用户分为四种角色（顾客、销售人员、仓库操作员、管理员），其中顾客可通过线上自助注册或由销售人员线下协助注册，其余角色由管理员在后台创建。

### 1.1 涉及角色

| 角色 | 可用功能 |
|------|----------|
| 匿名用户 | 注册、登录 |
| 顾客 | 登录、查看/修改个人信息 |
| 销售人员 | 登录、为线下顾客注册 |

### 1.2 涉及数据表

| 表名 | 说明 |
|------|------|
| `user` | 用户主表（账号、密码、角色） |
| `customer` | 顾客信息扩展表（姓名、性别、身份证号、手机、地址） |

## 3. 后端 API 设计

### 3.1 公开接口

#### POST `/api/auth/register` — 顾客注册

**请求体：**

```json
{
  "username": "13800138000",
  "password": "abc123",
  "realName": "张三",
  "gender": "男",
  "idCard": "310101199001011234"
}
```

**校验规则（后端）：**

| 校验项 | 说明 |
|--------|------|
| 用户名唯一 | 查询 `user` 表，已存在则返回 "用户名已被注册" |
| 身份证号唯一 | 查询 `customer` 表，已存在则返回 "该身份证号已注册" |
| 密码强度 | 6-20 位，至少包含字母和数字 |

**处理逻辑：**

1. 校验通过 → 密码 bcrypt 加密
2. 开启事务 → `user` 插入 → `customer` 插入（user_id 关联）
3. 提交事务 → 返回成功

---

#### POST `/api/auth/login` — 用户登录

**请求体：**

```json
{
  "username": "13800138000",
  "password": "abc123"
}
```

**响应：**

```json
{
  "code": 200,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "id": 1,
      "username": "13800138000",
      "role": "customer",
      "realName": "张三"
    }
  }
}
```

**Token 载荷：**

```json
{
  "userId": 1,
  "username": "13800138000",
  "role": "customer"
}
```

> Token 有效期 7 天，过期需重新登录。

## 4. 中间件

### 4.1 auth.js — JWT 认证

```
请求 → 从 Authorization 头提取 Bearer Token
     → jwt.verify(token, JWT_SECRET)
     → 成功：解码载荷注入 req.user = { userId, username, role }
     → 失败：返回 401 { code: 401, message: "请先登录" }
```

### 4.2 role.js — 角色校验

```
auth 中间件之后 → 比对 req.user.role 与允许角色列表
               → 不在列表中：返回 403 { code: 403, message: "权限不足" }
               → 在列表中：放行
```

使用示例：

```js
router.get('/admin/sales', auth, role(['admin']), adminController.listSales);
router.post('/users/offline-register', auth, role(['sales']), userController.offlineRegister);
```

## 5. 业务规则

| 编号 | 规则 |
|:----:|------|
| BR-U01 | 注册时用户名（手机号）和身份证号均需唯一性校验 |
| BR-U02 | 密码使用 bcrypt 加密存储，不在日志和响应中明文出现 |
| BR-U03 | 姓名、性别、身份证号注册后不可修改（数据库层面通过业务逻辑保证，不设触发器） |
| BR-U04 | JWT Token 过期时间为 7 天，前端 401 响应时自动清除 Token 并跳转登录页 |
| BR-U05 | 同一个人（同一身份证号）不能重复注册 |
| BR-U06 | 销售人员创建的线下顾客，初始密码为身份证号后 6 位，提示顾客首次登录后修改 |

## 6. 数据库操作摘要

| 操作 | SQL 类型 | 说明 |
|------|:--------:|------|
| 注册 | INSERT × 2 | 事务：`user` + `customer` |
| 登录 | SELECT | `user` 按 username 查，比对 bcrypt |
| 查个人信息 | SELECT + JOIN | `user` JOIN `customer` ON user_id |
| 改手机号 | UPDATE | `customer.phone` |
| 改地址 | UPDATE | `customer.address` |
