# 模块一：商品浏览与管理

---

## 1. 模块概述

商品模块是系统的核心模块，面向**所有用户角色**提供商品浏览功能，面向**管理员**提供商品管理功能。该模块负责商品信息的展示、搜索、筛选，以及商品的上架/下架和规格参数维护。

### 1.1 涉及角色

| 角色 | 可用功能 |
|------|----------|
| 匿名用户（未登录） | 浏览商品列表、查看商品详情 |
| 顾客 | 浏览商品列表、查看商品详情 |
| 管理员 | 浏览 + 商品添加、编辑、上架/下架 |

### 1.2 涉及数据表

| 表名 | 说明 |
|------|------|
| `product` | 商品主表 |
| `product_spec` | 商品规格参数表（EAV 模式） |
| `inventory` | 库存表（关联查询库存数量） |

### 2.3 管理后台 — 商品管理 (`/admin/products`)

> 仅管理员可访问。

| 编号 | 功能 | 描述 |

**请求参数：**

## 4. 业务规则

| 编号 | 规则 |
|:----:|------|
| BR-P01 | 下架商品不在前台商品列表中展示 |
| BR-P02 | 库存为 0 的商品详情页显示"暂时缺货"，加入购物车和立即购买按钮禁用 |
| BR-P03 | 商品类型 `category` 字段为枚举值，需在配置中统一管理，添加商品时从配置读取选项 |
| BR-P04 | 规格参数的分组相同的行，在详情页中合并到同一个分组标题下展示 |
| BR-P05 | 删除商品前须检查关联订单，有未完成订单则禁止删除并给出提示 |
| BR-P06 | 编辑商品不影响已有订单的快照价格（订单表 `order_item` 存储下单时的价格快照） |

## 5. 数据库操作摘要

| 操作 | SQL 类型 | 说明 |
|------|:--------:|------|
| 商品列表查询 | SELECT + JOIN | `product` LEFT JOIN `inventory` 获取库存，支持动态 WHERE 条件 |
| 商品详情查询 | SELECT × 2 | 先查 `product`，再查 `product_spec` WHERE product_id |
| 添加商品 | INSERT × N | `product` 插入 1 行 + `product_spec` 批量插入 N 行 |
| 编辑商品 | UPDATE + DELETE + INSERT | 更新 `product`，删除旧 spec 行，批量插入新 spec 行 |
| 上架/下架 | UPDATE | 更新 `product.status` |
| 删除商品 | DELETE × 2 | 先删 `product_spec`，再删 `product`（事务） |
