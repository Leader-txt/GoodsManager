# 模块三：购物车

---

## 1. 模块概述

购物车模块允许**已登录顾客**在浏览商品时暂存意向商品，支持调整数量、删除商品项，并在结算时校验库存有效性。未登录用户无法使用购物车功能。

### 1.1 涉及角色

| 角色 | 可用功能 |
|------|----------|
| 匿名用户 | 不可用（提示登录） |
| 顾客 | 完整购物车功能 |
| 其他角色 | 不可用 |

### 1.2 涉及数据表

| 表名 | 说明 |
|------|------|
| `cart` | 购物车表（如采取数据库存储） |

> **设计决策**：购物车数据可存储于数据库（持久化，多端同步）或仅前端 Pinia + localStorage（简单）。本次推荐**数据库存储**方案，便于后续扩展。若课程设计要求简化，可改为纯前端方案。

#### 2.1.2 功能需求

| 编号 | 功能 | 描述 |
|:----:|------|------|
| C-01 | 购物车列表 | 加载当前顾客购物车中所有商品项 |
| C-02 | 修改数量 | [+]/[-] 按钮调整数量，最小为 1；触及时实时更新后端 |
| C-03 | 删除商品 | 点击 [删除] 移除该行；弹出确认提示防止误删 |
| C-04 | 选中/取消 | 每行有复选框；全选/取消全选 |
| C-05 | 批量操作 | 仅选中的项参与合计计算；[去结算] 仅对选中项生效 |
| C-06 | 库存校验 | 若某商品当前库存不足（为 0 或低于购买数量），该行标红并提示"库存不足"，不可选中 |
| C-07 | 金额计算 | 实时计算选中项小计和总计；数量变化时自动更新 |
| C-08 | 空购物车 | 购物车为空时显示空状态插图和"去逛逛"引导链接 |
| C-09 | 去结算 | 携带选中商品和数量，跳转到结算页 `/checkout` |

## 3. 后端 API 设计

> 所有接口均需 JWT 认证（顾客角色）。

#### GET `/api/cart` — 获取购物车列表

**响应：**

```json
{
  "code": 200,
  "data": {
    "items": [
      {
        "id": 1,
        "productId": 1,
        "productName": "联想拯救者R9000P",
        "productImage": "/images/product_1.jpg",
        "price": 8999.00,
        "quantity": 1,
        "stockQuantity": 10,
        "selected": true
      }
    ]
  }
}
```

#### POST `/api/cart` — 加入购物车

**请求体：**

```json
{
  "productId": 1,
  "quantity": 1
}
```

#### PUT `/api/cart/:id` — 修改数量

```json
{ "quantity": 3 }
```

#### DELETE `/api/cart/:id` — 删除购物车项

#### DELETE `/api/cart` — 清空已选（结算成功后调用）

```json
{ "ids": [1, 2] }
```

## 4. 业务规则

| 编号 | 规则 |
|:----:|------|
| BR-C01 | 只有登录顾客可以操作购物车，未登录点击"加入购物车"弹出登录提示 |
| BR-C02 | 加入购物车时校验库存，购买数量不得超过当前库存 |
| BR-C03 | 购物车中同一商品多次加入时合并数量（而非创建新行） |
| BR-C04 | 进入结算页时对购物车选中项再次校验库存，因为加入后库存可能已变化 |
| BR-C05 | 结算成功后，已结算商品从购物车中移除 |

## 5. 数据库设计补充

### 购物车表 (`cart`)

```sql
cart (
    id            INT PRIMARY KEY AUTO_INCREMENT,
    user_id       INT NOT NULL,             -- FK → user.id
    product_id    INT NOT NULL,             -- FK → product.id
    quantity      INT NOT NULL DEFAULT 1,
    created_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_user_product (user_id, product_id)  -- 同一用户同一商品只有一行
)
```

---

## 6. 数据库操作摘要

| 操作 | SQL 类型 | 说明 |
|------|:--------:|------|
| 获取购物车列表 | SELECT + JOIN | `cart` JOIN `product` JOIN `inventory`，按 user_id 查 |
| 加入购物车 | INSERT ... ON DUPLICATE KEY UPDATE | 利用唯一约束实现去重合并 |
| 修改数量 | UPDATE | `cart.quantity` |
| 删除购物车项 | DELETE | 按 id 或 id 列表 |
